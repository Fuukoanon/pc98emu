pc98emu
=======
Over the course of the past few years I have been 
trying to write emulators for all sorts of hardware,
even for a pc9801, but it never went anywhere.

I don't know what else program. I should have learned
my lesson from last time that a lot of hardware 
specific to the pc9801 is only documented in Japanese
language, and as such I won't be able to decipher a
lot of the code, neither do I own a pc9801 machine 
to even test or reverse-engineeer, so it's kind of 
expected for this project to be hopeless. I will
try anyways, since I don't know what else to program.
